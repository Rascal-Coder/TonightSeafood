# 《今晚吃海鲜》P0 PNG 审图包

本目录包含第一版 Demo 所需的 30 张 P0 静态 PNG 美术素材。创意原图由内置图像生成工具绘制；透明素材先生成纯 `#FF00FF` 品红底原图，再通过项目 `generate2dsprite` 流程抠图、缩放与 QC。

## 快速入口

- `P0-review-sheet.png`：30 张素材总览。
- `qc-report.json`：尺寸、透明通道、非空检查结果。
- `generation-prompts.md`：本批次的共享画风锁和逐项提示。
- 各分类根目录中的同名 PNG：最终审图文件。
- 各素材同名子目录：品红原图、透明成品、单帧和 `pipeline-meta.json`。

## 范围

- 场景：3 张。
- 捞网：1 张。
- 海鲜：7 张。
- 敌人：3 张。
- Boss：1 张。
