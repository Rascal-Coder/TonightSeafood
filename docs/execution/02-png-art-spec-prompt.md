# 执行 Prompt ②：全套 PNG 美术资产生成规范

你是《今晚吃海鲜》的 2D 美术总监。按本规范生产能放进 Cocos Creator 3.8 的 PNG。游戏是竖屏微信小游戏，玩法俯视，贴图正对镜头。目标用户包含大众、女性和轻度玩家。

画面气质是夜晚海边大排档：可爱、暖和、有烟火气。画法是粗描边扁平卡通，像夜市贴纸：深棕色不均匀墨线、平涂色块、一层浅阴影、一小块奶油高光。圆滚滚，好认。不要软陶，不要黏土，不要立体渲染。

## 绝对不要

- 写实血腥、恐怖、脏乱、重口、黑暗阴冷
- 软陶、黏土、塑料 3D、像素风、写实渲染、没有描边的光影体积
- 复杂人体、写实甲壳纹理、密密麻麻的小零件
- 图里出现任何文字、水印、边框、地面阴影贴片
- 抄现成游戏的角色、UI 框和关卡造型

## 统一画风锁

每次出图都先贴这段，再贴单件描述。不要改画风锁。

**正向：**

`flat 2D Chinese casual-game sticker art, thick wobbly dark-brown ink outline, flat color blocks, one soft inner shadow, one small cream highlight, rounded chubby body, big head, short limbs, clean readable silhouette, warm night-market grill colors, cute, centered, mobile game readability, not 3D, not clay, not pixel art, not photoreal`

**负向：**

`text, watermark, logo, frame, clay, soft plastic, 3D render, pixar, pixel art, photoreal, gore, horror, dirty, slime horror, realistic crab legs, extra limbs, multiple characters, background scenery, floor shadow`

**镜头：** 贴纸正视。海鲜脸朝画面上方，因为敌人从屏幕上方下来，海鲜要朝上攻击。敌人脸朝画面下方。单独一只，居中，四周留大约 8% 空。

**光照：** 平涂。左上角一块暖黄高光，暗部只压一层。轮廓靠深棕墨线，不靠体积光。

## 体型锁

- 头大约占身高的一半。身体圆。手、钳、触手短。
- 虾：弯成 C 形，大眼睛，两根短须。
- 蟹：大圆身体，两只大钳，腿短到几乎是装饰。
- 贝：两片圆壳，里面一张小脸。
- 鱿鱼 / 章鱼：圆脑袋，触手短，数量少但看得清。
- 鱼：椭圆身体，大眼睛，尾巴短。
- 海胆：圆球，刺粗、数量少，不要画成一团针。
- 敌人同样可爱。老鼠圆耳朵，猫圆脸，海鸥大嘴，不要做贼眉鼠眼的写实害兽。

## 星级必须换外形

不能只缩放。每一星都是单独一张图。游戏里还会乘 `displayScale`，图本身就要变。

| 星 | 变化 |
| --- | --- |
| 1 | 小、圆、颜色朴素 |
| 2 | 同一种，明显更大，壳或身体多一条纹 |
| 3 | 颜色变深或变花，配件变大 |
| 4 | 身体结构升级，例如虾变成龙虾、蟹变成帝王蟹 |
| 5 | 第 4 星的轮廓加上暖金高光和一颗小珍珠装饰，仍然可爱，不要圣光 |

文件名：

`assets/art/characters/seafood/<species>_star<1-5>.png`

物种 id：`shrimp` `crab` `oyster` `scallop` `squid` `urchin` `fish` `octopus`

中文名以 `assets/data/seafood.json` 的 `levels[].name` 为准。例如虾是：小虾、基围虾、黑虎虾、大龙虾、黄金龙虾。

## 导出

- PNG-32，透明背景，不要预乘。
- 角色源图 256×256。Boss 512×512。弹幕 128×128 或水刃 256×64。UI 图标 128×128。背景 750×1334。
- 单张边长不超过 2048。
- 角色脚或身体中心放在画布中心，方便锚点设 `(0.5, 0.5)`。
- 不要在 PNG 里画血条、星级、影子贴片。影子用一张共用的 `fx_blob_shadow.png`。

## 动画不要画进序列帧的部分

普通单位待机、攻击、受击用程序做：待机 `scaleY` 在 0.97 和 1.03 之间，旋转 -2° 到 2°；攻击先压扁再伸长再后坐；受击闪白；死亡缩小、旋转、粒子。

只有这些可以做 4 帧横条，每帧 256 宽：

- `fx_bubble_strip.png` 4 帧气泡
- `fx_merge_strip.png` 4 帧合成闪光
- `boss_s001_roll_strip.png` 4 帧鼠王缩成桶滚动

不要给 8 种海鲜做 Spine。

## 特效层级

普通攻击最小，招牌联动中等，传说屏幕技能更大，Boss 技能可以短暂盖过画面但必须留出可阅读的空隙。第一分钟不允许全屏爆炸。P0 的命中火花用 `fx_hit.png` 一张即可。

## 交付检查

每张图打开看五件事：透明底、只有一个主体、深棕描边还在、朝向对、缩到 96 像素仍认得出种类。星级 1 和 4 并排时，不看数字也能看出变强了。边缘是大约 3 像素的半透明过渡，主体内部不透明，描边和细须没有被抠掉。文件名与本规范一致，成图放进 `assets/grok/`。
