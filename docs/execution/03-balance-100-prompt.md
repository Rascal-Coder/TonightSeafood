# 执行 Prompt ③：100 条 Build / 敌人 / Boss 正式数值

你是《今晚吃海鲜》的数值策划。本文件是正式夜的数值说明。产品流程在 `04-commercial-night.md`。没有 Demo 局。

程序仍只读 `assets/data/*.json`。那些 JSON 和 `tools/generate-balance.mjs` 还是旧数字。不要运行 `emit-balance-prompt.mjs` 覆盖本文件，直到生成器按这里改完。两边冲突时，以 `04-commercial-night.md` 文末「要改的数字」和本文件现在写的为准。

## 修改规则

- 源文件是 `tools/generate-balance.mjs`。JSON 是生成物。改完运行 `node tools/generate-balance.mjs`，再运行 `node tools/emit-balance-prompt.mjs` 刷新本文件。
- 不要在战斗脚本里写另一套数字。
- 不要把升级做成纯粹的攻击 +10%。每条都要改机制、操作或取舍。现有 57 条已经按这个原则写好，调整时保持这个性质。
- 敌人强度用波次倍率，不要给每一波手写一套新怪物。
- 反制是加压，不是让玩家的 Build 失效。单波被针对的单位数量不超过该波 40%。

## 六种料理

### C001 蒜蓉

命中挂香伤。同一目标每第 4 次命中爆香。 适合：shell、shrimp。

```json
{
  "dotDamage": 3,
  "dotInterval": 0.5,
  "dotDuration": 2,
  "explodeEveryHits": 4,
  "explodeRadius": 48,
  "explodeDamageMul": 0.4
}
```

### C002 麻辣

攻速提高。每 5 次攻击辣油弹跳。 适合：shrimp、octopus。

```json
{
  "intervalMul": 0.85,
  "chainEveryAttacks": 5,
  "chainJumps": 2,
  "chainDamageMul": [
    0.7,
    0.5
  ],
  "burnDps": 4,
  "burnSec": 2
}
```

### C003 椒盐

暴击时破甲并追加击退。 适合：crab、urchin。

```json

  "critAdd": 0.12,

  "armorShred": 0.2,
  "shredSec": 3,
  "knockbackAdd": 18
}
```

伤害提高，弹道留下燃烧路径。 适合：fish。

### C005 清蒸

自身伤害降低，周期性加快附近友军攻速。 适合：scallop。

## 招牌联动

这些是机制变化。料理和海鲜同时满足才触发，传说升级 B055 除外。

- **蒜香爆汁**（C001 + oyster）：命中时爆炸半径 70，伤害为该次命中的 55%。取代普通爆香。
- **麻辣连弹**（C002 + shrimp）：每 5 次攻击辣油跳 3 次，伤害系数 0.70 / 0.50 / 0.35。
- **椒盐重钳**（C003 + crab）：暴击击退再乘 1.8，并硬直 0.25 秒。
- **冰墨**（C006 + squid）：墨圈半径 64。敌人在墨圈内停留 0.6 秒后冻结 0.9 秒。
- **火焰水刃**（C004 + fish）：水刃路径留下 4 点/秒灼烧，持续 2.5 秒，路径宽 36。
- **鲜味蒸汽**（C005 + scallop）：每 5 秒给扇形内友军 +20% 伤害，持续 4 秒。

## 执行时怎么用

1. 战斗、UI、敌人全部读 JSON，id 对不上就报错。
2. 改平衡先改本文件和 `04-commercial-night.md`，再改 `tools/generate-balance.mjs`。生成器按这里改完之前，不要运行 `emit-balance-prompt.mjs`。
3. 手玩验收看这三件事：一只 1 星小虾能在鼠走到锅前打死同路一只偷吃鼠；同路两只鼠叠在一起会漏；铁桶鼠会逼玩家把重击拖到它所在的那一路。
4. 若实机手感偏离，优先改基础伤害、敌人生命和路程，不要先叠新乘区。
